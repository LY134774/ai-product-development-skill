## 可重复检查

在仓库根目录运行（已有 Python 3.9 或更新版本即可，无需安装依赖）：

```bash
python -B scripts/validate.py
python -B -O scripts/validate.py
python -B scripts/test_validate.py
python -B scripts/validate_evals.py
```

检查命名与目录一致、入口 frontmatter、Codex 元数据、版本格式、许可证一致性、10 份模板、Markdown 本地路径链接、参考文档可达、UTF-8、代码围栏和常见密钥格式。验证器使用显式异常报告失败，不再使用会被 `python -O` 跳过的 `assert`。

上一版 v1.1.0 已记录：33 个文件在普通与优化模式下检查通过；11 项回归测试通过，命令退出码均为 0。本版新增文件的实际 CI 结果必须以 GitHub Actions 运行记录为准，不预先声称已通过。回归测试只在临时副本制造错误并自动清理：正常仓库、坏链接（普通/优化模式）、越界链接、错误名称、重复 YAML 键、缺失模板、不一致许可证、无效 UTF-8、不可发现参考文档、疑似秘密、非法 YAML 不回显值。它们验证的是检查器，不是产品功能或宿主自动触发。

YAML 检查器只接受本仓库使用的块映射、字符串和布尔值子集；遇到超出范围的 YAML 语法会报错，不声称是通用 YAML 解析器。链接检查覆盖当前 Markdown 的简单行内本地路径，不能验证页内锚点、所有 Markdown 语法或远端 URL 状态。代码围栏检查是数量检查，不是完整 Markdown 解析。模板里的待填写字段是有意保留，不属于未完成的 Skill 脚手架。
